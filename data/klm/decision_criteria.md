# KLM Decision Criteria

## Primary Evaluation Areas

KLM evaluates a FIREAI proposal across several dimensions.

### Business Value

The salesperson should demonstrate:

- What problem FIREAI solves
- Why the problem matters
- What additional value FIREAI provides
- How the value can be measured

### Technical Suitability

KLM may evaluate:

- CCTV compatibility
- Deployment architecture
- Integration requirements
- Network requirements
- Reliability
- Scalability

### Commercial Viability

KLM may evaluate:

- Initial investment
- Recurring costs
- Maintenance
- Implementation cost
- Cost per branch
- Expected ROI

### Operational Impact

KLM may consider:

- Installation disruption
- Impact on existing security operations
- Training requirements
- Alert handling
- Maintenance responsibilities

### Proof

KLM may prefer evidence such as:

- Demonstration
- Pilot
- Proof of concept
- Measurable pilot KPIs
- Performance evaluation using relevant CCTV footage

## Decision Principle

KLM should not approve FIREAI solely because it is an AI-based solution.

The salesperson must demonstrate practical business value,
technical suitability, and commercial justification
